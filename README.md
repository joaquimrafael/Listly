# 🛒 Listly — Shopping List Manager

A full-stack web application for managing shopping lists online,
built with a Java Spring Boot REST API and a React frontend.

> 📊 [View Product Presentation](https://docs.google.com/presentation/d/16s76TrL4bKF6QCReBg-xTgAVYvUnitAzul_cwLkX4jw/edit?usp=sharing)

---

## 🚀 Tech Stack

| Layer | Technology |
|---|---|
| Backend | Java · Spring Boot · REST API |
| Frontend | JavaScript · React |
| Database | SQLite |

---

## ✨ Features

- 📋 Create and manage multiple shopping lists
- ✅ Add, edit and remove items from lists
- 🌐 Web-based interface accessible from any browser
- 🔄 Real-time data sync between frontend and backend via REST

---

## 🏃 Getting Started

### Prerequisites
- Java 17+
- Node.js 18+
- Maven

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm start
```

The app will be available at `http://localhost:3000`.
